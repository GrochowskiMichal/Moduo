- **2026-10-07 · Emailed links use fixed, allow-listed origins, and public booking is rate-limited.** booking-public used to build the guest email's Cancel link from `body.origin`, which any caller can set, so anyone could make noreply@moduo.app mail any address a link to their own domain (and have Google invite ten more). Now `_shared/app-origin.ts` decides every emailed link: the page's `origin` only picks among our own booking hosts (moduo.app, www, staging; no dev server, so production never mails a localhost link), and anything else gets `https://moduo.app`; the booking still goes through. A `book` is capped by `booking_rate_check()` at 10 per IP per hour, then 30 per host per hour (HMAC'd IPs via the shared `clientIp`, a server-only ledger keyed to the host with an `auth.users` cascade, same shape as `waitlist_join`). There is deliberately no platform-wide cap: one would let ~30 IPs switch booking off for every host, while the per-host cap can only throttle one host. The check runs only for a valid booking of an offered slot, right before anything is created or sent, so junk requests and a guest's own typos never count; only a missing function (deploy before migration) lets bookings through unchecked. The booker's email must be a plain address (it is Resend's `to`), the name is one line, an unknown time zone falls back to UTC, and a `book` on a paused link now gets an error instead of the preview payload the page read as booked. The guest page names which limit tripped. What the guest typed is HTML-escaped in the Google event description, which Google renders and mails to every invitee. send-workspace-invite escapes the inviter and workspace names (`_shared/escape.ts`: no line breaks, controls or bidi overrides, cut by code point) and links to `/join?invite=` on the app (`APP_URL` only when it is an app host, else `https://app.moduo.app`) instead of the nonexistent `/workspace/join?token=` on the marketing site; `SITE_URL` is no longer read. → `supabase/migrations/20261007120000_booking_rate_limit.sql` · `supabase/functions/_shared/app-origin.ts` · [docs/testing/t-maciej-booking-origin-allowlist.md](../testing/t-maciej-booking-origin-allowlist.md)
