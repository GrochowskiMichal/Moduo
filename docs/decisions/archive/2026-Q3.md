Ratified/decided in build: **(a) A Rust `RunEvent::ExitRequested` arm** in [lib.rs](../../../src-tauri/src/lib.rs) `.run(|app, event| …)` — macOS ⌘Q raises app-level `ExitRequested` (NOT any window's `CloseRequested`), so the JS `onCloseRequested` guard can't see it; when opted in it calls `api.prevent_exit()` + shows a native `tauri-plugin-dialog` confirm (Quit/Cancel). **(b) Pref bridged via a `set_confirm_before_quit(bool)` command** ([system.rs](../../../src-tauri/src/commands/system.rs)) into `AppState.confirm_before_quit: Mutex<bool>` — the pref lives only in the webview store, unreachable from Rust; chose the command-mirror (option a) over an emit-to-webview round-trip because it's **synchronous in the handler**. The webview pushes on boot + every toggle via a second effect in [confirm-before-quit.ts](../../../src/lib/confirm-before-quit.ts) (BOTH on AND off, so turning it off restores instant ⌘Q). **(c) Quit-after-confirm uses `std::process::exit(0)` (after `stop_all_idle_workers()`), NOT `app.exit()`** — Tauri v2 forbids `app.exit()`/`restart()` inside the `RunEvent` handler (re-enters `ExitRequested` → loop/panic; tauri `00e1567` / issue #5500), and the dialog callback runs on a later loop turn where the hard exit is clean. **(d) Non-blocking `.show(cb)`, never `blocking_show()`** — the plugin docs warn `blocking_show` deadlocks on the main/event-loop thread. **(e) No new capability** — `dialog:default` already covers the native message dialog (only the JS destroy path needed `core:window:allow-destroy`, added by base DF-19f-quit). **(f) Row copy de-caveated** — dropped "On macOS, ⌘Q still quits right away" → "Ask for confirmation before quitting the app, whether you press ⌘Q or close the window." The two guards are disjoint (⌘Q never fires `onCloseRequested`) → no double prompt. **⚠ Crux to confirm on the real build:** that ⌘Q actually raises `ExitRequested` in v2 (old v1-era threads waver) — ON → ⌘Q shows the confirm, Cancel keeps open, Quit exits; OFF → ⌘Q instant; the red-button guard still works. → [specs/df-19f-notification-toggles.md](../../../specs/df-19f-notification-toggles.md) §Confirm-before-quit · [docs/gotchas.md](../../gotchas.md) §Tauri · [docs/testing/df-19f-quit-cmdq.md](../../testing/df-19f-quit-cmdq.md)
