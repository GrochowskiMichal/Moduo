- **2026-10-08 · BRAND-1: every brand file is generated from `brand/masters/` by `bun run brand:export`** (built on `t/maciej/brand-1-asset-pipeline`; `bun run verify` 1781 green; live-checked on a local web build: the sign-in mark renders from the generated path and every favicon/email logo is served). Decided in build: **(a) masters are flat SVGs** (viewBox + filled paths only), so recolouring is exact and a design-tool export with transforms/clips/strokes/text fails loudly; `mark.svg` keeps the 1000-unit square box because that box *is* the icon/favicon geometry. **(b) Provisional masters = today's artwork, copied in unchanged:** the regenerated `favicon.svg` and both macOS icon sources render pixel-identical to the old ones, so the native icons didn't need a rebuild. **(c) Consumers:** `public/` favicons (they also serve the landing, whose build copies the web build, so `landing/` needs no copies), `public/email/{lockup,mark}-{light,dark}@2x.png` at the email spec's T6 location, on the exact canvases TX-1's `assets.ts` fixes (lockup 192 × 44 = 96 × 22 displayed, left-aligned and vertically centred; footer-badge mark 26 × 26); TX-1 uses these instead of rasterising its own. A Paper halo for the light variants (TX-1's request for apps that force dark mode) is built but off (`EMAIL_LIGHT_HALO_PX = 0`): brand decision 25 bans outlines and glows, so it waits for Maciej, the generated `src/components/ui/moduo-mark-path.ts` that `ModuoMark` renders, and `scripts/icons/source/`. **(d) Small sizes switch to `mark-small.svg` automatically** once Maciej draws it: favicon tiles ≤ 32 px (mark ≈ 23 px) and `<ModuoMark small />` (the 14 px booking badge uses it). **(e) Brand hex lives only in `scripts/brand/palette.ts`**, tested against `tokens.css`. **(f) A drift test in `verify`** compares every generated SVG and the TS module byte for byte with what the exporter makes from today's masters, so a master *or a rule* changed without a re-export fails (PNG bytes aren't compared: rasterisers differ by platform). **(g) `assets/icon.png` stays until BRAND-2**, which replaces its last use (the default profile picture). Found: the mark inside the old lockup file is a slightly different drawing from the app mark (aspect 1.333 vs 1.324); BRAND-0 settles it when the three masters are exported together. → [brand/README.md](../../brand/README.md)

- **2026-10-08 · Pink is not Moduo's accent and there is no "AI disc"; pink stays only as one ordinary accent/tag option** (designer-decided, brand decision 40). Traced because pink "keeps popping up": at the 2026-05-11 foundation grill, a pink circle in Maciej's first-draft screenshot was used to make pink the default accent. The brief written that day relabelled the circle the "AI disc" and made it a rule. It was built as a pink AI button in the bottom bar on 2026-05-13 and removed in the same PR. After that it survived only as copied text (CLAUDE.md until 2026-07-20, PRODUCT_BRIEF §7, landing-agents-readme, the moduo-design-quality skill, the landing's unused `--ai` var); the default accent became mono on 2026-07-27. **Now:** no AI colour, dot or badge anywhere; assistant actions show the assistant's name in the normal neutral style. Pink remains one of the eight Settings accents and tag colours, nothing more. Every guidance copy was removed or annotated in the same change; history docs (REVISION_DELTA, TASKS, DESIGN_REVIEW, audits) were left as history. **Agents: never treat pink as the default, brand or AI colour.** → [.design/brand/DECISIONS.md](../../.design/brand/DECISIONS.md) #40

- **2026-10-08 · Brand system planned: the product is the brand; drawn wordmark; no brand hue; pink isn't a brand colour; the mark reveals itself out of nothing** (designer-decided; Maciej makes every brand call). The brand is the app's own neutral system at a louder volume, with no brand hue, second typeface or illustration style. Geist is the only face; Pilat Extended leaves the font picker. The logo is the mark + the **drawn** lowercase wordmark (the Geist-typed "moduo" in the landing nav, emails and OG image is a stand-in to replace). Maciej is redrawing both masters, so everything downstream is generated from `brand/masters/` and re-exported. Two named blacks: Canvas (pure) and Reading (oklch 0.2, long text). (superseded the same day: there is no AI dot, see the entry above). The logo animation follows the mark's own rule: overlaps cancel, so with three strokes stacked the mark is invisible, and the side strokes slide apart to reveal it (once per launch, video intros, landing first visit; never looped). Voice: plain, calm, direct. Brand line "One window for the whole working life."; campaign line "Fire ten apps. Keep the work."; American English; boilerplate names no location (the founders move to Japan before release) and lists chat. The press kit gets built soon (BRAND-5) instead of waiting for release. Build blocks BRAND-0 (Maciej's masters) … BRAND-6; BRAND-1 (asset pipeline) unblocks the email build's logo. → [.design/brand/BRAND_BRIEF.md](../../.design/brand/BRAND_BRIEF.md)
