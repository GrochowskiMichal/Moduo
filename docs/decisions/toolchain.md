# Decisions: Toolchain and libraries

Full entries for this area, newest first. The one-line index of every area is [docs/decisions.md](../decisions.md). Add new entries at the top here **and** a one-line pointer in the index.

- **2026-10-08 · Subframe is removed.** It was never wired in: `src/ui/` held only a README and a theme mirror that nothing imported, `@subframe/core` had no importers, and no synced components existed. Maciej and Mike no longer plan to use it, so the folder, `.subframe/`, the package, the MCP server and the lint exemptions for `src/ui` are gone. Design components come from shadcn primitives in `src/components/ui/` and `tokens.css` only. → [docs/agent-setup.md](../agent-setup.md)

- **2026-10-08 · Storybook is 10.6.1, with `@storybook/addon-mcp`.** Replaces the 2026-10-07 call to stay on 8.6.18: the official upgrader (8 → 9.1.20 → 10.6.1) migrated the addons itself. `addon-essentials` and `addon-interactions` are now built into core, `addon-docs` is separate, and the `docs.autodocs` setting went away (stories tagged `autodocs` still get docs pages). Storybook 10 ships only the `storybook` binary, so the scripts call `storybook dev` / `storybook build`; `@storybook/cli` and the unused `@storybook/testing-library` are removed. `addon-mcp` serves component docs and story tools at `http://localhost:6006/mcp` while Storybook runs. It is opt-in per machine (`claude mcp add`), not in `.mcp.json`, so only machines that do UI work register it; on those, a session started while Storybook is stopped simply shows the server as failed. Its story-testing tool needs `addon-vitest`, which isn't installed because tests run on Rstest. The `.design-sync` Storybook configs got the same addon change plus the `@contracts` alias. → [.storybook/main.ts](../../.storybook/main.ts) · [docs/agent-setup.md](../agent-setup.md)

- **2026-10-08 · Claude Code gets TypeScript code intelligence from TypeScript 7's own language server, through a project plugin.** TypeScript 7 has no `tsserver`, so the official `typescript-lsp` plugin can't start; `tsc --lsp --stdio` from `node_modules` can. The plugin lives in the repo (`tools/claude-plugins/ts7-lsp`, listed by the root `.claude-plugin/marketplace.json` as marketplace `moduo-local`) and is enabled in `.claude/settings.json`, so both machines get it on trust. It gives go-to-definition, references, hover and symbols. It does not push per-file diagnostics after edits, so type errors still come from `bun run typecheck`. → [tools/claude-plugins/ts7-lsp/](../../tools/claude-plugins/ts7-lsp/) · [docs/agent-setup.md](../agent-setup.md)

- **2026-10-07 · Biome doesn't lint `landing/**`, and `bun run lint:js` gates CI.** The landing page is hand-written classic script with intentional CSS fallbacks, deployed separately from the app; Biome 2.5.15 started linting inside HTML and produced 41 errors there (15 more on `landing-v4`). Turning linting off for that folder keeps the app's lint meaningful; the page keeps its own review. CI now runs Biome, so `verify` and CI agree. → [biome.json](../../biome.json) · [checks.yml](../../.github/workflows/checks.yml)

- **2026-10-07 · The rest of the JS libraries move to their newest stable release, with four majors left on the line already in use.** TypeScript is 7.0.2 (the 7.1 nightly is not taken). Lucide is 1.52, Motion is 14, react-markdown is 10, the Stripe Node library used by the bootstrap script is 23, Biome is 2.5.15, and Zod is 4.6.5 in both the app and the Edge Function import map. Storybook stays on 8.6.18 (10 drops the addon packages the stories are configured with; 11 is an alpha). jsdom stays on 28 because 30 requires a newer Node than this machine runs. jest-dom stays on 6.10 because 7 is built for Vitest and the suite runs on Rstest. The live billing functions stay on `stripe@14` and API version `2023-10-16`. lightningcss stays pinned at 1.30.1. → `package.json` · `supabase/functions/deno.json`

- **2026-10-07 · Drag and drop stays on `@dnd-kit/core` 6.3.1, `@dnd-kit/sortable` 10.0.0, and `@dnd-kit/utilities` 3.2.2.** Those are the newest stable releases of this set (last published December 2024); their `next` tags are older. The successor, `@dnd-kit/react` 0.5.0, is a different API still before 1.0, and its beta is only a patch ahead of that. Switching would rewrite every drag surface (tasks, calendar, notes, contacts) for no change a person would see. → `package.json`

- **2026-10-07 · The Lexical pack is 0.52.0, and Yjs is 13.6.33.** Every `@lexical/*` package notes, email, and the spine text fields import is pinned to that release together, including html, table, and clipboard (they were floating as dependencies before). The nightly is one patch ahead and the old `next` tag is stale, so stable is the one that shipped. Syntax colors stay on Prism: 0.51 stopped re-exporting the highlighter from `@lexical/code`, so the notes editor imports `registerCodeHighlighting` from `@lexical/code-prism`. The new Shiki highlighter and the extension-based composer are not adopted. → `package.json` · `src/features/notes/ui/note-editor.tsx`

- **2026-10-07 · Tailwind CSS and `@tailwindcss/postcss` are both 4.3.3.** They had drifted (core 4.1.13, PostCSS plugin already on 4.3). The new scrollbar utilities are not adopted: `.scrollbar-thin` in `global.css` also paints the thumb with tokens, which the built-in utility does not. → `package.json` · `src/global.css`

- **2026-10-07 · React and React DOM are 19.3.0.** The jump from 19.2.8 is the stable View Transitions API, Fragment refs, and Trusted Types passthrough. None of those are turned on yet. → `package.json`

- **2026-10-07 · Unit tests run on Rstest 0.12, not Vitest.** Same suite, same one-file-at-a-time limit, same `@/` and `@contracts` aliases. Playwright stays the browser runner. Rstest is still pre-1.0; the move is for one toolchain with Rsbuild, and the suite has to stay green on this version. → `rstest.config.ts`

- **2026-07-29 · Biome 2.5.6 adopted as the JS/TS linter + formatter; `lint:js` joins `bun run verify`.** The repo had NO JS linter (only the custom `lint:tw` + stylelint). Config: [`biome.json`](../../biome.json) — format profile matched to existing style (2-space/double/semicolons/100-col/all trailing commas) so the one-time normalization diffs are pure whitespace+import-order (688 files); `assist/source/organizeImports: on`; CSS handed OFF to stylelint (Biome's v2 CSS parser chokes on Tailwind v4 at-rules — excluded `!**/*.css` + Subframe's `src/ui/**`); Deno supabase/functions excluded; build outputs (`dist`, `storybook-static` — which is TRACKED in git, a committed artifact, flagged) excluded. Rule severity policy: everything Biome flagged as an error that we can't justify → **fixed in-session** (10 iterable-callback/iterator-drain/key/finally sites + runtime.types format); chronic-but-real classes kept at **warn** for graduated burn-down (`useExhaustiveDependencies` ×94, a11y set ×~90, `noArrayIndexKey` ×21, optionalChain/useTemplate infos); `noExplicitAny`+`noNonNullAssertion`+`noParameterAssign` OFF (matches existing mapper patterns). Gate fails on errors only — warnings surface but don't block. Test exit behavior confirmed. → [docs/gotchas.md](../gotchas.md) §Repo/build

- **2026-07-29 · Compiler-codegen violations fixed app-wide; heavy routes code-split.** 17 render-time `xRef.current = x` writes (the latest-ref idiom, forbidden under concurrent rendering) converted to `useEffect` syncs — the React-sanctioned pattern; 3 memo-dep bugs fixed (`dashboard-data-context` stale `empty` via `emptyRef`, `appearance.ts` `syncsField` hoisted to module scope, habits-widget loop); `use-tasks-module` `orphanId` invariant → module-level pure `dropFailedTag`; ref-capturing `useState` factory in `use-email-compose` → mount-effect hold init. Result: refs errors 28→4 (remaining = 2 deliberate leaves), 5 files fully recovered to clean compile, all remaining bail-outs are SWC-port TODOs (try/finally) that resolve upstream. `useMemo(() => new YjsEngine())` + `tasks-plan-view` one-shot deep-link ref reads documented as deliberate leaves in gotchas. **Code splitting:** `/notes` `/email` `/mindmap` `/p/$token` now `lazyRouteComponent` boundaries — entry 950→675 KB gzip (−29%, 13 async chunks). `babel-plugin-react-compiler` removed (native SWC path never used it — proven by byte-identical chunk hashes). → [docs/gotchas.md](../gotchas.md) §Repo/build

- **2026-07-28 · React Compiler v1.0 enabled — automatic memoization across the app.** React 19.2.0→19.2.8 (hygiene, all patches RSC-only), Rsbuild 1.7.5→2.1.8 (native Rust-based React Compiler support via `pluginReact({ reactCompiler: true })`), babel-plugin-react-compiler@1.0.0 installed. verify green (1221 tests), all builds pass. The compiler auto-memoizes components at build time — no code changes needed. Existing `useMemo`/`useCallback` calls become no-ops under the compiler (safe to leave in place). Legend State's `use$` is compiler-incompatible but Legend State is not yet installed. → [specs/toolchain-upgrade-react-compiler.md](../../specs/toolchain-upgrade-react-compiler.md)
