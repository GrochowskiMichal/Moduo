- **2026-07-08 · Dashboard DB-1 (pure grid engine) landed** (`bun run verify` 864 green; skeptical-senior validator brute-forced 90k+ runs → core sound, no correctness blockers). The bounded-grid physics live in a zero-dependency `src/features/dashboard/engine/` (no React/DOM/time/random) so they're exhaustively fuzz-testable and reusable. Confirmed engine contracts: **(a) reject, never wrap** — `resolveDrag` pins the active widget at the clamped target, greedily relocates displaced widgets to their nearest free slot, and returns **null** (→ UI snap-back) when everyone can't fit, rather than wrapping a widget to the far edge; it's conservative (may reject a near-full drop a global repack could fit) — acceptable-by-design since reject == snap-back. **(b) greedy nearest-free ≠ cascade push** — a displaced bystander jumps to the closest open slot, not "shove the row over by one"; correct + terminating but the *feel* is a DB-3 sign-off item, not an engine change (gotchas). **(c) up-then-left compaction** is a deterministic idempotent fixpoint with a proven move-bound (cap 32·len+1); gaps always close, so you can't leave a hole (the ratified auto-compact model). **(d) immutability incl. config** — every op returns fresh widget objects with a *shallow*-copied `config` (validator CONFIRMED an aliasing leak where outputs shared the input/JSONB config reference; fixed at all boundaries incl. `sanitizeWidget`, the untrusted-input trust boundary); nested config still aliases one level down, so the app must edit config immutably. **(e) sanitize is total** — `sanitizeLayout` hand-rolls repair (drop unknown of the 16 `WIDGET_TYPES`, clamp coords, relocate overlaps, ≥1 page) and never throws on any adversarial JSONB → a corrupt row degrades to a valid compacted grid (AC11).
