- **2026-10-06 · Billing runs on the Stripe Sync Engine; Free is a real tier; four plans (Free / Pro $12 / Duo $20 / Team $15-per-seat).** (a) `stripe.*` is the mirror; `public.recompute_entitlement()` (DB trigger on `stripe.subscriptions`, plus `handle_new_user` and `founder_emails`) is the ONLY writer of `profiles.plan_tier / subscription_status / current_period_end`. Tier comes from the price's `metadata.plan_tier`; prices are found by `lookup_key` (`pro|duo|team` × `monthly|yearly`) so there are no `STRIPE_PRICE_*` secrets. (b) Client roles can no longer write billing columns on `profiles` (before: any signed-in user could set themselves `founder`). (c) `founder_emails` (mike@, maciej@moduo.app) always resolve to `founder`/`active`; a BEFORE trigger on `profiles` makes that unlowerable. (d) The web "paywall wall" is gone — Free works on web and desktop with limits (RLS: 1 workspace; seat caps Free/Pro 1, Duo 2, Team = paid seats, via restrictive policies on `workspace_invites`/`workspace_members`). `/paywall` is a Plans page. (e) Trials: 14 days no card (auto on first sign-in via `start-trial`), 30 days with a card (`extend-trial`, called after the Billing Portal return, or Checkout `withCard`); one trial per Stripe customer, ever. (f) Removed: custom `stripe-webhook` source (the installed Sync Engine owns that slug now — never redeploy the old one), `sync-subscription`, `trial-extension`, `subscription_events`, `stripe-tier.ts`, the `?price_id=` signup funnel.

- **2026-10-01 · Landing waitlist goes only through the `waitlist-join` Edge Function; `public.waitlist` is closed to anon/authenticated.** The legacy table had a wide-open INSERT policy and anon held every privilege incl. TRUNCATE (0 rows). Now: no policies, all grants revoked, writes via `public.waitlist_join()` (service_role only) which validates, rate-limits (8/hour per IP, 500/10 min global, advisory-locked) and inserts idempotently; the function answers `success` for duplicates and honeypot/too-fast bots so it never reveals membership. IPs are stored only as HMAC-SHA256 keyed by the project secret key (no new secret to manage); raw `ip_address` column dropped. `WAITLIST_SOURCES` (nav/hero/close) + `WAITLIST_STATUSES` live in `@contracts`. Nav/hero/close CTAs replace "Get started"/"Sign in". → `supabase/migrations/20261001160000_waitlist_secure_join.sql` · [docs/testing/t-mike-landing-v4.md](../testing/t-mike-landing-v4.md)
