Created by Maciej · Oct 6, 12:07 PM · Updated 7:20 PM
  1. No Plan/Focus switch in the rail. The rail looks the same in every module. Focus starts from the Queue (a ▶ in the Queue view's header).
  2. Rail rows: buckets get an icon slot (a dot, optionally coloured) so their labels line up with All / Queue / Inbox. Counts sit flush right; try Swap vs Shift in the bar above. Active and hover are now clearly different.
  3. Toolbar = one control language. Ghost buttons on one rung. Search · Filter · Display, then the view switch, with a properly raised active plate (today it's darker than its track on dark). "Group: Bucket" moves into Display. New stays the one primary.
  4. Display holds layout, group, order, completed (Hidden · 7 days · All), subtasks and which properties show on rows.
  5. Filter chips read as sentences (Assignee · is · Me ×), with a match count and Clear.
  6. Rows: no left bar; selection = tint (try Tint + hairline). Fixed right-hand columns (priority · date · assignee · queue) so meta lines up down the list. Title is followed by quiet counts: # tags, 📎, 💬, subtasks, blocked. No bucket pill inside a bucket group. The queue toggle only appears on hover, unless the task is queued. "In Mike's queue" shows his ringed avatar.
  7. Priority glyph has a fixed footprint with ghost bars (the level is read by fill, not by count). Energy is off on rows by default (Display), and on in the panel.
  8. Completed: hidden by default, with a quiet "5 completed · show" line at the end of each group.
  9. Detail panel:
    • The header now has a breadcrumb, the queue toggle, link and ⋯.
    • A checkbox sits next to the title. The description has no empty box below it.
    • Every property value starts at the same x, behind a 14px icon slot. No chevrons; hover shows the field. Placeholders are muted.
    • Estimate and time spent merge into one Time row with a hairline progress bar.
    • Tags become a property.
    • Collections share one header style (label · count · +). Attachments show as thumbnails.
    • Activity and comments sit at the bottom with a composer. "Created by" is in the last line.
  10. Scrollbars: thin and token-coloured by default everywhere (scroll the list).

4 · Focus = running your Queue

The sidebar never changes. Focus is a state of the Queue view: line tasks up, press ▶ Start run. While a run is on, the centre holds only what you're doing (Now) and what's next. Anything you hand off goes to the right panel under In flight, so the centre doesn't get busier as things pile up. Leave Tasks and the run follows you in the top-bar chip. Click the in-flight cards.
